Load the funds export and the funding file (stays on this device)

1. Funds export (.xlsx or .csv): Obligation, Disbursement and Commitments by line. Several exports are added together, so load each one only once. Only the nine columns below are read; every other column is ignored, and personal identifier columns (such as social security number) are skipped without being read. Lines whose Commitment Item is ALLOBJ are removed completely before anything is counted. The file is read by this browser tab only; nothing is uploaded, stored, or sent anywhere.

2. Funding file: one row per Functional Area (optionally also Fiscal Year, Appropriation, Sag, MDEP, Commitment Item) with TDP (full-year funding), AFP (funded to date) and Reservations (known costs not yet obligated). An optional Account column names each Functional Area. Funding is matched to the export lines on every column both files share.

3. Spend plan (optional): Fiscal Year, Functional Area or Account (both optional), Fiscal Month (1–12 where 1 = Oct, or a month name) and Planned Amount. It draws the plan line on the trend charts.

You can choose all the files at once; each is recognized by its headers.

How the numbers are calculated
  • Obligation and Disbursement are the export's cumulative amounts (obligation_amt_cum and disbursement_amt_cum), added up for the lines in the current filters. Commitments (commitment_amt_cum) is shown in the line table only.
  • TDP, AFP and Reservations come only from the funding file, never from the export. Without a funding file they show “Load funding file”.
  • Balance = TDP − Reservations − Obligation − Disbursement.
  • Fiscal Month comes from the export's fiscal_month (1 = Oct, 2 = Nov … 12 = Sep) and is shown as “1 - Oct”. Values like 01, 1.0, P01 or a month name are accepted; anything else counts as blank.
  • Spending trend: each line's amount counts in its fiscal month. “Spent” is Obligation + Disbursement by default (the same amounts Balance subtracts); you can switch it to Obligation or Disbursement only. The straight-line pace is TDP × month ÷ 12. The spend plan line is the cumulative Planned Amount.
  • Where we should be compares % of TDP spent with % of the year elapsed. For the current fiscal year, elapsed uses today's fiscal month (October = 1/12); a past year counts as 12/12. The trend shows the Fiscal Year filter if set; otherwise the current fiscal year once it has two months of data, else the latest earlier year.
  • Funding rows are matched to the lines on Functional Area plus any of Fiscal Year, Appropriation, Sag, MDEP and Commitment Item that both files have. Funding rows with the same match values are added together. Lines with no funding row still count in Obligation and Balance and are listed as “no funding row”.
  • When a filter uses a column the funding file does not have (for example Commitment Item when funding is by Functional Area), funding cannot be split, so the funding rows that have matching lines are shown at their full amount.
  • ALLOBJ lines (Commitment Item equal to ALLOBJ, any case or spacing) are removed when the file is read. They are never counted, charted, listed, exported, or saved.
  • Documents = distinct Document Numbers among the lines shown. A document can have several lines (one per Commitment Item).
  • Amounts accept commas, dollar signs, parentheses and trailing minus signs for negatives. Blank, #REF! and other error cells count as blank ($0 in totals).
  • Charts show the 10 largest values; the remainder is grouped as Other. A blank value is shown as (blank).
