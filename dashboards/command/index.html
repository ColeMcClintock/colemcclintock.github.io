How the numbers are calculated

Loading

  • Files are read by this browser tab only. Each file is matched to its page by its column headers (PR files also need L1–L4 in the name; fuel trackers are named for the AASF).
  • Loading a file again replaces the earlier copy of the same kind: the same funds file type, the same PR level, or the same AASF. Loading your first file clears the demo data.
  • Headers match regardless of case, spaces or underscores. Personal identifier columns (such as SSN) are skipped without being read. #REF! and other error cells count as blank.

Status of Funds

  • Obligation and Disbursement are the export's cumulative amounts, sign-flipped (× −1) because the export carries them negative.
  • TDP, AFP and Reservations come only from the funding file, per Account. Functional Areas roll up to Accounts (with their Sag and MDEP) through the Account Key. Commitment items sharing a description in the Commitment Item Key are added together.
  • Balance = TDP − Reservations − Obligation − Disbursement. Straight-line pace = TDP × fiscal month ÷ 12 (October = 1).

PR Tracker

  • The level comes from the file name: L3.xlsx = Level 3. Columns read: Cardholder Name (shown as First Last), Purchase requisition (PR Number), Merchant / Description (Merchant), Short Text (Description), Total Value.
  • Rows with the same PR number in one level are one PR. Its value is the sum of its rows, except when every row repeats the same amount (the PR total copied onto each line); then that amount is counted once.
  • A PR found in more than one level file is shown once, at the highest level.

Fuel

  • Each tracker's budget is cell B1; the table header (Date, Milstrip Number, Gallons, Total Cost) is found near row 13. Blank rows and total rows are ignored.
  • Fiscal year elapsed is counted in days from 1 October. On pace = spending within 10% of the straight-line budget pace; the projection is spend to date ÷ share of the year elapsed.
