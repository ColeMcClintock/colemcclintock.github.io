How the numbers are calculated
  • Window: the 12 months ending in the selected month, compared with the 12 months before it.
  • Mishap rate per 1,000 = Class A–D mishaps in the window ÷ average assigned strength × 1,000. Near misses are not counted as mishaps.
  • Mishap classes use illustrative cost bands: Class A $2.5M or more (or fatality / permanent total disability), Class B $600K to under $2.5M (or permanent partial disability), Class C $60K to under $600K (or a lost workday), Class D $25K to under $60K. Thresholds here are for demonstration.
  • Days lost are lost workdays; cost includes property damage and injury cost.
  • Days since last Class A/B counts from the most recent Class A or B in scope to the last day of the window.
  • Near-miss ratio = near misses reported per mishap. Higher ratios usually mean a healthier reporting culture.
