Status of Funds flow: expressions

Same flow as the Mishap dashboard (tracker + rollup), with two Excel tables (the funds export and the funding file) plus an optional third (the spend plan). Click Copy, then paste into the field named. The dashboard tells the two tables apart by their headers, so their order does not matter.

  1. Recurrence (your times, Central).
  2. Excel Online (Business) > List rows present in a table: the funds export in the restricted library, its table (Ctrl+T on the sheet; any table name). Settings: Pagination on, Threshold 100000. Leave the step name as List rows present in a table.
  3. Excel Online (Business) > List rows present in a table again: the funding file (columns Fiscal Year, Functional Area, Account, TDP, AFP, Reservations), table FundingData in the blank funding file. Power Automate names this step List rows present in a table 2; keep that name. Pagination on.
  4. Optional: List rows present in a table a third time for the spend plan (columns Fiscal Year, Functional Area, Account, Fiscal Month 1–12 or a month name, Planned Amount; table SpendPlanData in the blank spend plan). Keep the name List rows present in a table 3. Pagination on.
  5. SharePoint > Get file content: finance-dashboard-template.html. Infer Content Type = No.
  6. Compose: Inputs = expression below.
  7. SharePoint > Update file: your dashboard file (for example Funds_Dashboard.html), File Content = outputs('Compose').

Optional, step 2 > Show all > Select Query (reads only the 11 export columns; the SSN column and the rest are never pulled)

Step 5 (or 6 with a spend plan): Compose, Inputs (export + funding)

Compose, Inputs with the spend plan (export + funding + spend plan)

Last step: Update file, File Content

Only if Compose gives a base64 error: alternate Compose expression

If you renamed a List rows step, change List_rows_present_in_a_table / _2 / _3 to the new name with spaces as underscores. Without the funding step, use only the first addProperty(...) pair; the dashboard then shows “Load funding file” for TDP, AFP, Reservations and Balance.

The alternate expression above covers export + funding; for the spend plan, add the same third addProperty(...) pair as in the spend plan expression.

ALLOBJ lines are removed by the dashboard itself, so no filter is needed in the flow.
