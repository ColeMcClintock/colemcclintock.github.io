Status of Funds flow: expressions

Same flow as the Mishap dashboard (tracker + rollup), with one List rows present in a table step per Excel table. The dashboard tells the tables apart by their headers, so their order does not matter. Click Copy, then paste into the field named.

Step name (keep it)TableColumns
List rows present in a tableFunds exportthe GFEBS export (amounts negative; the dashboard flips the sign)
List rows present in a table 2Funding (FundingData)Fiscal Year, Account, TDP, AFP, Reservations
List rows present in a table 3Account Key (AccountKey)Functional Area, Account, Sag, MDEP
List rows present in a table 4 (optional)Commitment Item Key (CommitmentItemKey)Commitment Item, Description
List rows present in a table 5 (optional)Spend plan (SpendPlanData)Fiscal Year, Account, Fiscal Month, Planned Amount
  1. Recurrence (your times, Central).
  2. The List rows steps above, each on its file in the restricted library. Settings: Pagination on, Threshold 100000.
  3. SharePoint > Get file content: finance-dashboard-template.html. Infer Content Type = No.
  4. Compose: Inputs = one of the expressions below.
  5. SharePoint > Update file: your dashboard file (for example Funds_Dashboard.html), File Content = outputs('Compose').

Optional, export step > Show all > Select Query (reads only the 9 export columns; ssn, sag, mdep and the rest are never pulled)

Compose, Inputs: export + funding + Account Key

Compose, Inputs: all five tables (adds Commitment Item Key and spend plan)

Update file, File Content

Only if Compose gives a base64 error: alternate (all five tables)

To leave out a table, delete its addProperty(...) pair (and the comma before it). If you renamed a List rows step, change List_rows_present_in_a_table_N to the new name with spaces as underscores. Without the funding table the dashboard shows “Load funding file” for TDP, AFP, Reservations and Balance; without the Account Key every Functional Area shows as Unmapped.

ALLOBJ lines are removed and the export sign is flipped by the dashboard itself, so no filter or calculation is needed in the flow.
