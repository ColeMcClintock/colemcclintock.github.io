Status of Funds flow: expressions

Same flow as the Mishap dashboard, with one Excel table. Click Copy, then paste into the field named.

  1. Recurrence (your times, Central).
  2. Excel Online (Business) > List rows present in a table: the funds export in the restricted library, its table (Ctrl+T on the sheet; any table name). Settings: Pagination on, Threshold 100000.
  3. SharePoint > Get file content: finance-dashboard-template.html. Infer Content Type = No.
  4. Compose: Inputs = expression below.
  5. SharePoint > Update file: your dashboard file (for example Funds_Dashboard.html), File Content = outputs('Compose').

Optional, step 2 > Show all > Select Query (reads only the 9 columns; the SSN column and the rest are never pulled)
