About this portfolio

  • Privacy-first. Everything runs in your browser. Data you load never leaves your device; there is no server, tracking, or login.
  • Offline-capable. All libraries are bundled with the site. No internet or install needed; just open index.html.
  • Portable. Download the ZIP, unzip on any computer (including a locked-down work machine), and it runs as-is.
  • Bring your own data. Each tool documents a column template so real data can be swapped in locally.
  • Reproducible. Demo datasets are generated by a seeded script included in the repository.
